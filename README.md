# Digital Wilds

אבטיפוס מקורי למשחק גידול מפלצות והרפתקה, בהשראת משחקי תקופת PS1. **זה אינו שחזור של Digimon World ואינו משחק מלא**. אין כאן נכסים, מוזיקה, דמויות או קוד מהמשחק המקורי.

## הפעלה

נדרש Python 3. מתוך התיקייה:

```sh
python3 -m http.server 8080
```

פתחו http://localhost:8080. אין תלויות להורדה. בדיקות לוגיקה: `node --test` (Node 18 ומעלה).

## מה כלול

- עולם איזומטרי פרוצדורלי אחד, שחקן ושותף עוקב.
- בריאות, MP, שובע, אנרגיה וקשר; האכלה, מנוחה, אימון וריפוי.
- שלושה אויבים, קרב בזמן אמת, התקפה אוטומטית ויכולות בפיקוד השחקן.
- קניית מזון, משימת גיוס נוסע, בוס ותגמולי קרבות.
- Embercub → Pyroclaw → Solarmane → Aetherion או Void Seraph, שתי צורות מגה מקוריות.
- התפתחות לפי ניסיון וקשר, בחירת נתיב בשער הריק.
- ממשק בעברית, מקלדת וכפתורי תנועה למגע, שמירה ידנית ב־localStorage.

WASD/חצים לתנועה, E לאינטראקציה, רווח להתקפה, 1–3 ליכולות. אימון ליד אבן האימון במערב. מנוחה רק במחנה. הבסת שומר הבקע משלימה את יעד האבטיפוס. אויבים חוזרים לאחר 60 שניות פעילות. כישלון מאפשר חזרה למחנה ב־E במחיר עד 15 מטבעות.

## מגבלות והמשך פיתוח

הגרפיקה היא Canvas איזומטרי ב־2D, ולא מנוע תלת־ממד PS1. חסרים עולם מלא, התנגשויות עם תפאורה, סיפור ארוך, סאונד, אנימציות מקצועיות, מערכת גיל ומוות/לידה מחדש, צרכים מתקדמים, תפריטים מלאים ואיזון משחק ממושך. כרגע אפשר ללכת דרך עצים. הצורות והיכולות מקוריות ומצומצמות. שמירה מקומית ידנית בלבד, והאויבים מתאפסים בטעינה מחדש.

מבנה: `core.js` מצב וחוקי משחק; `game.js` ציור, קלט ועולם; `style.css` ממשק; `core.test.js` בדיקות.
